Predicción de demanda de transporte

SERIE DE TIEMPO

Este módulo corre el mismo código del notebook directamente en tu navegador usando Pyodide (Python/WebAssembly). Sin servidor: carga los datos reales del CTA, entrena dos redes neuronales profundas (MLP de 3 capas y MLP de 4 capas), y genera el pronóstico de 30 días a partir del último registro disponible en el dataset — no desde la fecha de hoy.

Control de ejecución

Presiona el botón para cargar Python y correr el notebook.
Los pasos de ejecución aparecerán aquí…

1Dataset — CTA Bus Ridership

Datos del Chicago Transit Authority (2001–2026). Se filtra desde 2021 y se toman las 10 rutas de mayor demanda.

2Exploración — Media móvil 7 días por ruta

3Estacionalidad y tendencias

Descomposición aditiva de la serie (tendencia + estacionalidad semanal + residuo), patrón promedio por día de semana y evolución anual por ruta.

4Ingeniería de variables

Se añaden rezagos (lag_1, lag_7), media móvil de 7 días (rolling_7) y variables de calendario (día de semana, mes, fin de semana, festivo). Estas variables convierten la serie en un problema supervisado de regresión tabular.

5Resultados del modelo por ruta

Partición temporal 80/20 — el 20% más reciente se usa como set de prueba. Se comparan dos redes neuronales (MLP-3 capas y MLP-4 capas). El modelo ganador por ruta se selecciona por menor RMSE.

6Validación — Real vs. Predicción (4 rutas)

7Pronóstico operativo — 30 días
