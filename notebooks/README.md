# Herramientas en Colab

Los notebooks están pensados como herramientas ejecutables y no solo como evidencia de código. Cada uno incluye contexto, carga de datos, exploración, entrenamiento, evaluación y una sección final de uso con parámetros editables.

| Notebook | Herramienta | Resultado de uso |
|---|---|---|
| `01_prediccion_demanda.ipynb` | Predicción de demanda por ruta | Pronóstico diario de los próximos 30 días |
| `02_clasificacion_conduccion.ipynb` | Clasificación visual de conducción distractiva | Clase predicha y probabilidad por categoría |
| `03_recomendacion_destinos.ipynb` | Recomendación personalizada de destinos | Top-K destinos con explicación |

Los notebooks no requieren clonar el repositorio. Cargan datos livianos desde archivos públicos del proyecto o generan una muestra reproducible cuando no hay conexión.
