El CF puro es el mejor predictor porque el dataset tiene suficiente densidad de interacciones. El filtrado por contenido solo no puede distinguir entre destinos del mismo tipo. El híbrido es más robusto para usuarios con pocos datos históricos.

Metodología
Dataset

Kaggle Travel Recommendation — 1 000 destinos indios, 999 usuarios con preferencias declaradas, ~2 000 interacciones (reviews + historial).

Filtrado colaborativo

Matriz usuario × destino (858×866). Similitud coseno entre usuarios (diagonal=0). Score = suma ponderada de ratings de vecinos, normalizada a [0,1].

Filtrado por contenido

Score = 0.7 × (tipo ∈ preferencias) + 0.3 × popularidad normalizada. Híbrido: 70% CF + 30% contenido.
