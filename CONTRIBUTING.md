# Contribución

## Flujo

1. Crear una rama descriptiva.
2. Ejecutar `python scripts/run_all.py`.
3. Ejecutar `pytest`.
4. Abrir pull request con resumen, evidencia y capturas si aplica.

## Estilo

- Mantener módulos separados por responsabilidad.
- No subir datasets grandes de Kaggle.
- Guardar métricas en `outputs/metrics/`.
- Guardar figuras en `outputs/figures/`.
