# Aspectos Éticos y Creatividad

## Privacidad

El sistema puede trabajar con datos sensibles: imágenes de conductores, historial de viajes y preferencias de usuarios. Se deben aplicar principios de minimización, anonimización y control de acceso.

## Consentimiento

Las imágenes de conductores deben recolectarse con consentimiento informado y finalidad explícita. El sistema no debe emplearse para vigilancia desproporcionada.

## Sesgos

Los modelos pueden reproducir sesgos presentes en los datos:

- Rutas con mayor volumen pueden recibir mejores predicciones.
- Clases visuales con más imágenes pueden tener mejor desempeño.
- Destinos populares pueden dominar las recomendaciones.

## Uso responsable

Las predicciones deben apoyar decisiones humanas. En especial, la clasificación de conducción distractiva debe tratarse como señal de alerta y no como prueba definitiva.

## Creatividad

La propuesta integra tres problemas normalmente separados en una sola herramienta: eficiencia operativa, seguridad vial y experiencia personalizada del usuario.
