# Scripts

Scripts esperados:

- `generate_sample_data.py`: prepara archivos procesados reproducibles para ejecutar los módulos.
- `prepare_real_datasets.py`: prepara los datasets reales descargados para imágenes, recomendación y demanda de transporte.
- `train_demand.py`: entrena y evalúa predicción de demanda.
- `train_vision.py`: entrena o prueba el clasificador de imágenes.
- `train_recommender.py`: entrena y evalúa el recomendador.
- `run_all.py`: ejecuta todo el flujo.
