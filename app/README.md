# Herramienta Web

La aplicación web se implementará con Streamlit.

Funcionalidades:

- Visualizar predicciones de demanda por ruta.
- Subir una imagen de conductor y obtener la clase predicha.
- Seleccionar un usuario y generar recomendaciones de destinos.

Comando esperado:

```bash
streamlit run app/streamlit_app.py
```
